# Security policy

## Reporting a vulnerability

Report privately through [GitHub security advisories](https://github.com/jakhongirjp/taskforge/security/advisories/new).
Please include steps to reproduce and the commit you tested.

You'll get an acknowledgement within 3 working days and a fix or mitigation
plan within 14 days for high and critical issues. Credit is given in the
release notes unless you ask otherwise.

## Supported versions

Only the latest release on `main` receives security fixes.
